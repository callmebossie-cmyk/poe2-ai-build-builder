# Passive artwork provenance

skills.json and skills.webp are the unmodified passive icon atlas published by
Grinding Gear Games in poe2-skilltree-export, revision
bd87e6512c92b868542eddfb1ba4ea8b6dc2da36.

Source: https://github.com/grindinggear/poe2-skilltree-export/tree/bd87e6512c92b868542eddfb1ba4ea8b6dc2da36/assets

Artwork belongs to Grinding Gear Games. Downloaded files are ignored by Git.
The predev/prebuild script fetches and verifies them locally to render the pinned
tree without runtime network requests. Update both files together with
the pinned tree data; do not mix game-data revisions.
